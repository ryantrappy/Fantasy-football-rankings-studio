# Feature coverage for the expanded mockups

This is a design review map, not evidence that the production redesign is implemented. TASK-146 remains To Do. Existing production components, calculations, provider integrations, persistence, security and exports remain the implementation baseline. No feature reduction has been approved.

## Review decisions retained

- Seven main destinations: Rankings studio, Weekly overview, Live matchups, Season insights, Playoff simulator, League history, Other tools.
- Players and Trade analyzer remain under Other tools. Profile, Create league and Manage leagues stay in the top-right account menu.
- Weekly overview shows all sample managed-league matchups together.
- Live matchups keeps its compact sidebar and dense four-quarter board, with two complete roster columns per game.
- The original rankings export stylesheet and geometry remain unchanged. TASK-147 is only the future optional rankings export theme choice.
- Definitions use accessible information tooltips. Source evidence, settings, missing-data states, meaningful caveats and controls remain reachable; informational dropdowns are not substitutes for features.

## Validation boundary

The mockups use illustrative datasets. CSV/JSON files generated here contain sample data. Scenario calculations are deliberately bounded local fixtures. Provider transactions, credential storage, authentication, publication and real exports do not run. Server-managed Codex instructions explain the existing operator workflow; no account connection or AI request is made.

Production implementation must reuse existing league-specific slot/scoring rules, provider coverage, unknown values, privacy boundaries, account-scoped selections, save-conflict/recovery logic, sharing controls, immutable archives and background computation. Tests of these standalone screens do not establish correctness of those production systems.
