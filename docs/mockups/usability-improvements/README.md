# UI & Usability Improvements Mockup (`usability-improvements`)

An interactive, 100% feature-preserving redesign prototype built on top of the approved Manager Explorer palette (`#F3F5FB` workspace, `#FFFFFF` surfaces, `#17223B` navy, `#3949AB` indigo, `#EEF1FF` selection fill, `#DCE2EE` dividers) and documented preservation contracts in [`../../feature-preservation.md`](../../feature-preservation.md) and [`../../manager-explorer-coverage.md`](../../manager-explorer-coverage.md).

Open [`index.html`](index.html) directly in a browser to explore all 12 screens, toggle **Show UX improvement callouts**, and test every interactive workflow. Existing review assets in `../app-explorer/` remain completely untouched.
