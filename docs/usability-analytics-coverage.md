## Delivered behavior

- Season insights keeps a Selected team inspector alongside all seven views. Selecting a scoring/position/schedule team updates context without changing the current view; only the explicit Open in Weekly trends action changes views. The all-team filter remains available. Inspector values use real season totals, weighted legal-slot accuracy, lineup coverage and the existing remaining-schedule calculation. Missing calendars remain unavailable.
- Position cells show exact points and tied ranks with fixed blue ranks 1–2, green 3–4, amber 5 and coral 6+ tiers; missing data stays gray. The stacked chart explicitly includes 0–2200, expands for larger real scores and retains negative segments. Original positional identities, custom positions, modes, sorting, provider, scoring, horizon, refresh and incomplete-coverage notices remain.
- Forecast Table / Histogram toggles preserve cutoff and selection. Histogram bars show observed final-win frequencies from the existing simulation trials, including half-wins; exact win counts, probabilities and configured playoff-seed frequencies are accessible and downloadable. Seed 0 explicitly means did not qualify. Saved forecasts without frequency data report unavailable distributions. Bar heights scale to each team's modal count, with percentages printed above each bar.
- The selected playoff path persists through Table, Histogram, Week-by-week and Advanced. It includes the cutoff record with ties, projected wins, qualification, supported bye probability, every configured advancement/title round and actual provider bracket/tiebreaker/reseeding rules. Team selection is available directly in the inspector.
- Season/league selectors, refresh and compact sharing use the shared inline PageHeading command bar. Existing sharing controls and critical privacy/snapshot notices remain in the shared ShareReport disclosure.
